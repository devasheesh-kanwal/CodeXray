Agent repair loop

Branch → fix → test → evaluate → human approval

  1. CoordinatorAssigns tasks and logs progress
  2. ArchitectMaps relevant modules
  3. Create fix branchKeep the main branch untouched
  4. Debug and repairUse code and past failures
  5. Test runnerRun tests in a sandbox
  6. Evaluation gateCheck tests, regressions, and lint

Pass: review

Human approves before merge.

Fail: retry

Delete the fix branch and try again.

Three failures: stop

Report the result to a human.

A passing change is reviewed by a person before it is merged to main.
